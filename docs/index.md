## Config files

| File | Use |
|------|-----|
| [appsettings.json](../Mcp.Server/appsettings.json) | Masked template. Copy to `appsettings.local.json` in `AppContext.BaseDirectory` (build output for `dotnet run`, beside the binary for a release). Gitignored. |
| [.mcp.json](../.mcp.json) | Committed Cursor Directory config (`npx -y mssql-mcp-tools`). No secrets. |
| [launcher/](../launcher/) | npm launcher that downloads the pinned GitHub Release |
| [mcp.example.json](../mcp.example.json) | Cursor MCP when running from source |
| [mcp.release.example.json](../mcp.release.example.json) | Cursor MCP for Windows release binary |
| [mcp.release.unix.example.json](../mcp.release.unix.example.json) | Cursor MCP for Linux / macOS release binary |
